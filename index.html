Automated CentOS Database Backups

Overview / Problem

Needed a reliable, hands-off disaster recovery solution to protect a database hosted on a CentOS 9 server.

Result / Impact

Implemented a zero-touch backup infrastructure ensuring high data availability and rapid recovery capabilities in the event of hardware failure.

Specific Tasks Executed

  • Built a synchronized server cluster utilizing Hadoop in a CentOS 9 CLI VM hosted on a Hyper-V Server.
  • Developed custom BASH scripts to automate the archival process.
  • Utilized rsync over SSH for secure, efficient delta transfers of database dumps.
  • Configured cron jobs to schedule regular, unattended backup intervals.
